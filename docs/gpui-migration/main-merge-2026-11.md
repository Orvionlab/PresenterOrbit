## Shared data and host boundary

Workspace schema remains strict **version 1**. There are no migrations, legacy aliases or schema fallbacks. Main expands content and supported effect fields, not the workspace version. Both apps read/write through the same workspace implementation, including GPUI's unchanged-section guards.

New top-level settings: `presenterOrbitWorkspaces` (validated name/path registry). The workspace commands own it; generic settings saves strip it from incoming payloads so a stale UI cannot overwrite it. Existing settings are shallow-merged, preserving the stored registry. GPUI retains canonical settings as JSON, edits sections through its revision lane, and accepts the full `settings-changed` payload. `workspace-list-changed` is harmless to GPUI's event dispatcher; a future workspace list must subscribe to it. Native workspace switching, creation and the folder picker share one activation path (`workspaces::Workspaces::activated`); `workspace-list-changed` refreshes the shared list (`workspaces/`).

General settings additions: `manageMediaAutomatically`, `relinkMissingMedia`, `altClickSuppressesVideoAutoStart`, `mediaSearchPaths`, `hiddenMediaSearchPaths`, `mediaSearchPathNames`, `foregroundAudioPresentation`, `foregroundAudioAnnouncements`, `importScaleForeground`, `importScaleBackground`, `importImageBehavior`, `importVideoBehavior`, `importVideoPlayback`, `importVideoEndBehavior`, `importAudioPlayback`, `autoEnableScreensAtLaunch`, `ignoreBackgroundColors`, `slideLabels`, `ndiShowLocalSources`, `ndiGroups`, `ndiExtraIps`. The shared normalizer accepts these; GPUI section edits clone the complete general settings and preserve them. This is data compatibility, not a claim that all native controls or consumers are implemented.

New shared modules from main live under `crates/orbit-host/src`: `general_settings_options`, `ndi_find_options`, `os_trash`, `sample_content`, `workspace_registry`, plus `default_content.json`. Reuse the existing `dirs` version for native known-folder resolution rather than Tauri APIs in the shared host. macOS trash uses `objc2-foundation`; Linux uses main's GIO implementation. These platform paths were not compiled on Windows.
