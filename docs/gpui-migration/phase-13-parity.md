## Automated evidence

Five new tests in `crates/orbit-app/src/media/view_tests.rs`:

- `two_thousand_media_scroll_input_through_frame`: 400 actual wheel events per grid/list layout on the GPUI test platform, foreground event-through-frame timing, collection debug/release budgets. Generated metadata-only items; no real window.
- `file_drop_handler_imports_a_real_path_and_ignores_unsupported_files`: generated real PNG plus unsupported text path; actual handler and host persistence; managed-copy bytes verified.
- `transport_draft_rejects_invalid_bounds_and_saves_one_complete_setting`: invalid drafts do not save; complete settings and null out point round-trip through the host.
- `asset_clipboard_and_presets_round_trip_through_the_workspace_lane`: copy/paste/cut, unique copy title/id, copied asset bytes, create/delete preset persistence, native preview pixels/dimensions.
- `missing_media_scan_and_reviewed_cleanup_use_the_real_host`: native missing scan, fingerprinted cleanup review and confirmed move to recovery.

Added while closing the phase (all in `view_tests.rs` unless noted): inline library rename Enter and blur, rename Escape, grid size, marker drafts, asset preview brightness, selection retirement, background swatches, `card_duration_prefers_probe_and_ignores_malformed_saved_text`, `thumbnail_failure_is_visible_and_a_stale_selection_ignores_it`, `closing_the_missing_media_dialog_retires_a_late_scan`, `effect_variables_persist_only_values_the_host_accepts`, `library_tree_mutations_reorder_nest_and_ignore_cycles_and_foreign_tabs`; plus unit tests in `menu.rs` (option defaults), `markers.rs` (repeat switch), `inspector.rs` (tabs and title) and `gesture.rs` (hold, cancel, retirement, gap targets).

TypeScript tests not ported because the behavior is not in the GPUI crate: the store and persistence queue tests (`media-settings-transport`, revision retries in `media-bin-controller-and-view`), the detached popup, DOM sizing helpers (`normalization-and-media-utils`), and part of the `media-markers` execution tests; phase 15 ported the guard, default, missing-path, and retirement cases and lists the rest in `phase-15-parity.md`. Blur through real focus loss, rename IME, and physical pointer drags are hand acceptance: the GPUI test platform does not deliver focus-loss events, so the blur test emits `InputEvent::Blur` from the input state.
